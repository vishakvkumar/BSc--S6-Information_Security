Why maths?

Why do we need maths in security?

In one line

A message can be read on its way to your friend, unless it is protected.

  • Encryption: turning readable text into unreadable text
  • Decryption: turning it back into readable text
  • Both are done with maths
Remember

Every encryption step must be undoable.

Example

The Caesar cipher

  1. 1Message: HELLO
  2. 2Shift each letter 3 forward: H→K, E→H, L→O, O→R
  3. 3Secret message: KHOOR
  4. 4Shift each letter 3 back: HELLO again

Maths tells us when the 'undo' is possible.

1.1

Groups, Rings and Fields

The rules that make 'undo' possible

1.1

What is a set?

In one line

A set is just a collection of things.

Example
A = {1, 2, 3}
C = {0, 1, 2, …, 11}
    (the numbers on a 12-hour clock)
ℤ = {…, −2, −1, 0, 1, 2, …}
    (all integers)
Remember

We will use the 12-hour clock set again and again.

1.1

What is a binary operation?

In one line

A rule that takes two things and gives one result.

Example
2 + 3 = 5
4 × 5 = 20
On a clock: 9 + 5 = 2
    (start at 9, move 5 hours)
Remember

'Binary' means it works on two things at a time.

1.1

What is a group?

In one line

A set with an operation that follows 4 rules, called A1 to A4.

  • A1 Closure
  • A2 Associativity
  • A3 Identity
  • A4 Inverse
Example
Our example:
the 12-hour clock
with + (adding hours)
Remember

A1 + A2 + A3 + A4 = Group

1.1

The four group rules

RuleSimple meaningClock example
A1 ClosureThe answer stays inside the set9 + 5 = 2, still a clock number
A2 AssociativityBrackets don't matter(3 + 4) + 5 = 3 + (4 + 5)
A3 IdentitySomething that changes nothing7 + 0 = 7, so 0 is the identity
A4 InverseEvery element has an 'undo'5 + 7 = 12 ≡ 0, so 7 undoes 5
Remember

Order of a group = number of elements. Clock: 12. Integers: infinite.

1.1

What is an abelian group?

In one line

A group where order doesn't matter: a + b = b + a. This is rule A5.

  • Abelian: ₹50 then ₹20 = ₹20 then ₹50. Same balance.
  • Not abelian: Rubik's cube. Top-then-right ≠ right-then-top.
  • The cube is still a group: every move can be undone.
Remember

Abelian = group + A5 (order doesn't matter).

Real life

Your Aadhaar number uses a group

In one line

The last digit of an Aadhaar number is a check digit made using a group.

  • It uses the Verhoeff algorithm
  • Built on the 10 ways to turn or flip a pentagon
  • It catches any one wrong digit
  • It catches two neighbouring digits swapped
Remember

A simple digit sum can't tell 38 from 83. This group can.

1.1

What is a cyclic group?

In one line

A group where repeating one element (the generator) reaches every element.

  1. 1Keep adding 5 on a 12-hour clock:
  2. 20 → 5 → 10 → 3 → 8 → 1 → 6 → 11 → 4 → 9 → 2 → 7 → 0
  3. 3All 12 reached, so 5 is a generator ✓
  4. 4Keep adding 4: 0 → 4 → 8 → 0
  5. 5Only 3 reached, so 4 is not a generator ✗

Every cyclic group is abelian. Used in Diffie–Hellman (Module 4).

1.1

What is a ring?

In one line

A set where you can add, subtract and multiply, but not always divide.

Example
Integers:
7 + 3 = 10   ✓
7 − 3 = 4    ✓
7 × 3 = 21   ✓
7 ÷ 2 = 3.5  ✗  not an integer
Remember

A ring has two operations: + and ×.

1.1

Remember

ℤ (integers) is an integral domain.

1.1

What is a zero divisor?

In one line

Two numbers that are not zero, but multiply to give zero.

Example
On a 12-hour clock (mod 12):
4 × 3 = 12 ≡ 0
4 ≠ 0 and 3 ≠ 0
Remember

ℤ₁₂ has zero divisors, so it is not an integral domain.

1.1

What is a field?

In one line

A set where you can add, subtract, multiply and divide (but never by 0).

  • Every non-zero number needs a multiplicative inverse
  • Example: 3 × ⅓ = 1, so ⅓ is the inverse of 3
Example
Fractions:
3/4 ÷ 2/5
= 3/4 × 5/2
= 15/8  (still a fraction ✓)
Remember

Field = all four operations work.

1.1

Field or not?

SystemField?Why
ℚ fractionsYesEvery non-zero fraction has an inverse
ℝ real numbersYesInverse of x is 1/x
ℂ complex numbersYesEvery non-zero number has an inverse
ℤ integersNo2 has no integer inverse
ℤ₇ 7-hour clockYesEvery non-zero number has an inverse
ℤ₁₂ 12-hour clockNo4 has no inverse mod 12
1.1 summary

Group → Ring → Field

  1. 1Group: one operation, with undo
  2. 2Ring: + and ×
  3. 3Field: + − × ÷ (not ÷ 0)

Ciphers use fields, because decryption must undo multiplication. AES uses GF(2⁸).

Modular Arithmetic

Maths on a clock

1.2

What is modular arithmetic?

In one line

Maths with remainders. a mod n = the remainder when a is divided by n.

  1. 1It is 10 o'clock
  2. 2Add 5 hours: 10 + 5 = 15
  3. 3A clock has only 12 hours: 15 mod 12 = 3

Answer: 3 o'clock. You already do this every day.

1.2

Practice: a mod n

QuestionWorkingAnswer
10 mod 310 = 3 × 3 + 11
15 mod 415 = 3 × 4 + 33
20 mod 620 = 3 × 6 + 22

25 mod 525 = 5 × 5 + 00
Remember

Find the biggest multiple of n that fits. What is left over is the answer.

1.2 · exam tip

Negative numbers

In one line

The remainder is always between 0 and n − 1. It is never negative.

  1. 1Find −11 mod 7
  2. 2Write −11 = (−2) × 7 + 3
  3. 3Or keep adding 7: −11 → −4 → 3

−11 mod 7 = 3 (not −4)

1.2

What is divisibility?

In one line

b | a means 'b divides a' with no remainder.

Example
6 | 24, because 24 = 6 × 4
5 does not divide 24
Divisors of 24:
1, 2, 3, 4, 6, 8, 12, 24
Remember

The symbol | means 'divides'. It is not division.

1.2

The division algorithm

In one line

Any number a can be written as a = q × n + r, where 0 ≤ r < n.

  • a = the number being divided
  • n = the divisor
  • q = the quotient
  • r = the remainder (r = a mod n)
Example
17 = 2 × 7 + 3

q = 2, r = 3
so 17 mod 7 = 3
Remember

The remainder r is always smaller than n.

1.2

What is congruence?

In one line

a ≡ b (mod n) means a and b leave the same remainder when divided by n.

Example
38 ≡ 14 (mod 12)
38 → remainder 2
14 → remainder 2
Quick check: 38 − 14 = 24,
and 12 divides 24 ✓
Remember

≡ is read 'is congruent to'.

1.2

Rules: reduce first, then calculate

OperationQuestionReduce first
Add(8 + 7) mod 5(3 + 2) mod 5 = 0
Subtract(12 − 7) mod 5(2 − 2) mod 5 = 0
Multiply(8 × 7) mod 5(3 × 2) mod 5 = 1
Remember

Small numbers are easier. RSA does this with numbers hundreds of digits long.

1.2

Big powers: 11⁷ mod 13

  1. 111² = 121 ≡ 4 (mod 13)
  2. 211⁴ = 4² = 16 ≡ 3
  3. 37 = 4 + 2 + 1, so 11⁷ = 11⁴ × 11² × 11
  4. 4≡ 3 × 4 × 11 = 132
  5. 5132 mod 13 = 2

Answer: 2. This trick is called square-and-multiply.

1.2

What is ℤₙ?

In one line

ℤₙ = {0, 1, 2, …, n − 1}. Every answer is reduced mod n.

Example
ℤ₈ = {0, 1, 2, 3, 4, 5, 6, 7}
6 + 5 = 11 ≡ 3
4 × 3 = 12 ≡ 4
Remember

ℤₙ is just the clock with n hours.

1.2

Two kinds of inverse in ℤ₈

InverseMeaningIn ℤ₈
AdditiveGives 0 when addedEvery number has one: 3 + 5 = 8 ≡ 0
MultiplicativeGives 1 when multipliedOnly 1, 3, 5, 7 have one. 2, 4, 6 don't.
Remember

So ℤ₈ is not a field.

1.2

What is a multiplicative inverse?

In one line

a⁻¹ is the number that gives 1 when multiplied by a (mod n).

Example
3 × 5 = 15
15 mod 7 = 1
so 3⁻¹ mod 7 = 5
Remember

a has an inverse mod n only if gcd(a, n) = 1.

1.3

Euclidean Algorithm and GF(p)

Finding GCDs and inverses

1.3

What is GCD?

In one line

Greatest Common Divisor: the biggest number that divides both numbers.

Example
Factors of 60:
1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60
Factors of 24:
1, 2, 3, 4, 6, 8, 12, 24
Biggest common factor: 12
Remember

gcd(60, 24) = 12

1.3

What are relatively prime numbers?

In one line

Two numbers whose GCD is 1. They share no common factor except 1.

Example
gcd(8, 15) = 1
8 = 2 × 2 × 2
15 = 3 × 5
nothing in common
Remember

8 and 15 are not prime, but they are relatively prime.

1.3

The Euclidean algorithm

In one line

A fast way to find GCD without listing factors: gcd(a, b) = gcd(b, a mod b).

  • 1. Divide the big number by the small number
  • 2. Note the remainder
  • 3. Replace (big, small) with (small, remainder)
  • 4. Repeat until the remainder is 0
Remember

The last non-zero remainder is the GCD.

1.3 · worked example

Find gcd(84, 36)

  1. 184 = 2 × 36 + 12
  2. 236 = 3 × 12 + 0 → stop

GCD = 12

1.3 · worked example

Find gcd(1071, 462)

  1. 11071 = 2 × 462 + 147
  2. 2462 = 3 × 147 + 21
  3. 3147 = 7 × 21 + 0 → stop

GCD = 21. The biggest square tile for a 1071 × 462 cm floor is 21 cm.

1.3

The extended Euclidean algorithm

In one line

It also finds x and y so that a·x + b·y = gcd(a, b).

  • If gcd(a, n) = 1, then a·x + n·y = 1
  • So a·x ≡ 1 (mod n)
  • So x is the inverse of a
Remember

This is how RSA finds its private key (Module 4).

1.3 · worked example

Find 15⁻¹ mod 26 · Step 1: divide

  1. 126 = 1 × 15 + 11
  2. 215 = 1 × 11 + 4
  3. 311 = 2 × 4 + 3
  4. 44 = 1 × 3 + 1

GCD = 1, so an inverse exists.

1.3 · worked example

Find 15⁻¹ mod 26 · Step 2: work backwards

  1. 11 = 4 − 3
  2. 2 = 4 − (11 − 2 × 4) = 3 × 4 − 11
  3. 3 = 3 × (15 − 11) − 11 = 3 × 15 − 4 × 11
  4. 4 = 3 × 15 − 4 × (26 − 15) = 7 × 15 − 4 × 26

15⁻¹ mod 26 = 7. Check: 15 × 7 = 105 = 4 × 26 + 1 ✓

1.3

What is GF(p)?

In one line

The numbers {0, 1, …, p − 1} with + and × mod p, where p is prime. It is a field.

  • GF = Galois Field
  • A field with a finite number of elements
Example
GF(7) =
{0, 1, 2, 3, 4, 5, 6}
Remember

GF(p) is a clock with a prime number of hours.

1.3

Inverses in GF(7)

NumberInverseCheck (mod 7)

353 × 5 = 15 ≡ 1

666 × 6 = 36 ≡ 1
Remember

Every non-zero number has an inverse, so GF(7) is a field.

1.3

Why must p be prime?

In one line

A prime shares no factor with smaller numbers, so every number has an inverse.

  • ℤ₈: 2 × anything is even, so never 1 mod 8 ✗
  • GF(7): every non-zero number has an inverse ✓
Example
Real life:
Bitcoin:
p = 2²⁵⁶ − 2³² − 977
WhatsApp:
p = 2²⁵⁵ − 19
Remember

Same idea as GF(7), just with very big primes.

1.4

What is an irreducible polynomial?

In one line

A polynomial that cannot be factored. It is like a prime number.

  • x⁴ + x + 1: cannot be factored, so irreducible ✓
  • x³ + x² + x + 1 = (x + 1)(x² + 1), so reducible ✗
Remember

We need irreducible polynomials to build finite fields.

1.4

Why do we need GF(2ⁿ)?

In one line

A byte has 8 bits, so 2⁸ = 256 values. But 256 is not prime, so mod 256 is not a field.

  • The fix:
  • 1. Treat each byte as a polynomial
  • 2. Multiply the polynomials
  • 3. Reduce by an irreducible polynomial of degree 8
Remember

Result: a field with 256 elements, called GF(2⁸).

1.4

A small example: GF(2³)

  1. 12³ = 8 elements: 000 to 111
  2. 2Irreducible polynomial: m(x) = x³ + x + 1
  3. 3So x³ = x + 1 (in GF(2), + and − are the same)
  4. 4Example: x × x² = x³ = x + 1

Rule: replace x³ with x + 1 whenever it appears.

1.4 · real life

AES uses GF(2⁸)

In one line

AES (Advanced Encryption Standard) does all its byte maths in GF(2⁸).

  • Its polynomial: m(x) = x⁸ + x⁴ + x³ + x + 1 (hex 11B)
  • To multiply two bytes: write as polynomials → multiply → reduce by m(x)
  • Example: {57} × {83} = {C1}
Remember

AES protects HTTPS websites, Wi-Fi and stored files.
