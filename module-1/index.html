1.1Abstract algebra · the setup

A set + an operation = a game with rules.

Definition

A binary operation • on a set G is a rule that takes any two elements a, b ∈ G and gives one result a • b. (∈ means “is an element of”.)

Example 1
{0,…,11}

Hours on a clock, combined by adding hours.

Example 2
ℤ, +

All integers …, −2, −1, 0, 1, 2, … combined by ordinary addition.

Example 3
Cube moves

Twists of a Rubik’s cube, combined by doing one twist, then another.

1.1Groups

A group {G, •} obeys four axioms.

Example throughout: a 12-hour clock with “add hours”.

A1

Closure

Combine any two members and you get a member.

a, b ∈ G ⇒ a•b ∈ G
9 + 5 → 2 o’clock
A2

Associative

Brackets don’t matter.

a•(b•c) = (a•b)•c
(3+4)+5 = 3+(4+5)
A3

Identity

There is a do-nothing element e.

a•e = e•a = a
7 + 0 = 7, so e = 0
A4

Inverse

Every a has a partner a′ that cancels it.

a•a′ = a′•a = e
5 + 7 = 12 ≡ 0
Order of a group

The number of elements in G, written |G|. A finite group has finitely many elements (clock: order 12); otherwise it is an infinite group (ℤ under +).

1.1Groups · examples

Test each axiom. One failure means no group.

Set, operationGroup?Why
ℤ, +YesIdentity 0; inverse of a is −a. Infinite group.
ℤ₁₂, + mod 12YesThe clock. Identity 0; inverse of a is 12 − a. Finite, order 12.

1.1A5 · commutative
a•b = b•a

Abelian group = group + axiom A5.

Order doesn’t matter. Get ₹50 then ₹20, or ₹20 then ₹50: same balance. Examples: (ℤ, +), the clock ℤ₁₂.

Non-abelian
a•b ≠ b•a

Order matters, but it is still a group.

Rubik’s cube: top-then-right ≠ right-then-top. Permutation group S₃. Every move can still be undone.

Case studyGroups in India

Your Aadhaar’s last digit is checked by a group.

The check digit C comes from the Verhoeff algorithm, built on the symmetry group of a pentagon, D₅.

Because D₅ is non-abelian, it catches every single wrong digit and every swap of two neighbouring digits.

A plain digit sum can’t tell 38 from 83. A non-abelian group can.

1.1Cyclic groups

Repeat one element, reach them all.

Exponentiation in a group

a³ = a • a • a,  a⁰ = e,  a⁻ⁿ = (a′)ⁿ
With + this is just 3a; with × it is a·a·a.

Definition · cyclic group

A group G is cyclic if every element of G is a power aᵏ (k an integer) of one fixed element a ∈ G. That element a is a generator of G.

  • Every cyclic group is abelian.
  • A cyclic group may be finite or infinite.
Examples

ℤ₁₂, +1, 5, 7, 11Adding 5 again and again visits all 12 hours

1.1Rings · the idea

A ring lets you add and multiply.

Works
+ − ×

Add, subtract and multiply always stay inside the set.

Breaks · integers
7 ÷ 2 = 3.5

Not a whole number. Division escapes ℤ.

Breaks · 12-hr clock
4 × 3 = 0

Two non-zero numbers multiply to zero, so “÷ 4” has no answer.

A ring is missing exactly one thing: division.

1.1Fields · the idea

A field: + − × ÷ all work.

Only rule: never divide by zero. Ciphers multiply during encryption, so they must divide to decrypt. Ciphers live in fields.

1.1Fields · formal definition

Field = integral domain + one more axiom.

M7 · multiplicative inverse

For every a ≠ 0 in F there is a⁻¹ ∈ F with a·a⁻¹ = a⁻¹·a = 1.
Division is then defined as a / b = a · b⁻¹.

Fields
  • ℚ rational numbers: inverse of 3/4 is 4/3
  • ℝ real numbers, ℂ complex numbers
  • ℤₚ, p prime, e.g. ℤ₇: inverse of 3 is 5 because 3·5 = 15 ≡ 1
Not fields
  • ℤ: 2 has no integer inverse
  • ℤ₁₂, any ℤₙ with n not prime: 4 has no inverse mod 12
  • 2×2 matrices: not commutative, and some have no inverse

1.2Divisibility

“b divides a” means no remainder.

Definition

b | a (read “b divides a”) if a = m·b for some integer m. Then b is a divisor of a.

Example · divisors of 24
1 2 3 4 6 8 12 24

Real world: 24 hours split evenly into shifts of 1, 2, 3, 4, 6, 8 or 12 hours, never 5.

Properties
1If a | 1, then a = ±1
2If a | b and b | a, then a = ±b
3Any b ≠ 0 divides 0
4If a | b and b | c, then a | c  (11 | 66, 66 | 198 ⇒ 11 | 198)
5If b | g and b | h, then b | (mg + nh) for any integers m, n
1.2Division algorithm

Every integer = quotient × n + remainder.

Division algorithm

For any integer a and positive integer n there are unique integers q, r with
a = q·n + r,  0 ≤ r < n,  q = ⌊a / n⌋
The remainder r is written a mod n; n is the modulus.

Positive a
11 = 1·7 + 4

11 mod 7 = 4

Negative a · the remainder is never negative
−11 = (−2)·7 + 3

−11 mod 7 = 3  (not −4)

1.2Interactive

Modular arithmetic is clock maths.

a mod n = remainder of a ÷ n

10 o’clock + 5 hours = 15 → 15 mod 12 = 3.

1.2Congruence

Congruent = same remainder.

Definition

a ≡ b (mod n)  if  a mod n = b mod n.  Read: “a is congruent to b modulo n”.

Properties
1a ≡ b (mod n)  ⇔  n | (a − b)
2a ≡ b ⇒ b ≡ a  (symmetric)
3a ≡ b and b ≡ c ⇒ a ≡ c  (transitive)
Examples
✓73 ≡ 4 (mod 23): 73 − 4 = 69 = 3·23
✓21 ≡ −9 (mod 10): 21 + 9 = 30
✓38 ≡ 14 (mod 12): both leave 2

Residue classes mod 4: every integer falls in [0], [1], [2] or [3]. e.g. [1] = {…, −7, −3, 1, 5, 9, …}

1.2Modular arithmetic rules

Shrink first, multiply later.

1. [(a mod n) + (b mod n)] mod n = (a + b) mod n
2. [(a mod n) − (b mod n)] mod n = (a − b) mod n
3. [(a mod n) × (b mod n)] mod n = (a × b) mod n

RSA does this with 600-digit numbers. It never computes the giant product.

Worked example
(1234 × 5678) mod 9
11234 mod 9 = 1
25678 mod 9 = 8
3(1 × 8) mod 9 = 8
✓7,006,652 mod 9 = 8

Also: (11 + 15) mod 8 = (3 + 7) mod 8 = 2

1.2Powers mod n

Big powers, small numbers.

To find a large power mod n, square repeatedly and reduce after every step. The numbers never grow beyond n².

RSA encrypts with c = mᵉ mod n, using exactly this trick.

111² = 121 = 9·13 + 4 → 4
211⁴ = (11²)² ≡ 4² = 16 → 3
37 = 4 + 2 + 1, so 11⁷ = 11⁴·11²·11

=11⁷ mod 13 = 2

1.2Key points to remember

Unit 1.2 in six lines.

1

b | a if a = m·b. Divisibility is transitive.

2

a = qn + r, 0 ≤ r < n. r = a mod n is never negative.

3

a ≡ b (mod n) ⇔ same remainder ⇔ n | (a − b).

4

5

6

1.3GCD

The biggest number that divides both.

Definitions

gcd(a, b) is the largest positive integer dividing both a and b.  gcd(a, 0) = |a|.
a and b are relatively prime if gcd(a, b) = 1.

By prime factors
60= 2² · 3 · 5
24= 2³ · 3
gcd= 2² · 3 = 12
Relatively prime
gcd(8, 15) = 1

Neither 8 nor 15 is prime, yet they share no factor.

Factoring a 300-digit number is practically impossible. Euclid’s method finds the gcd without factoring.

1.3Euclidean algorithm
300 BC

Euclid’s trick still runs in your phone.

gcd(a, b) = gcd(b, a mod b)

Picture a 1071 × 462 cm floor. The biggest square tile that fits exactly is the gcd.

1.3Euclidean algorithm · formal

Keep dividing. The last non-zero remainder wins.

Theorem

gcd(a, b) = gcd(b, a mod b)
Since a = qb + r, any number dividing a and b also divides r = a − qb, and the other way round.

Euclid(a, b):        // a ≥ b ≥ 0
  while b ≠ 0:
      r ← a mod b
      a ← b
      b ← r
  return a           // = gcd
Worked example · gcd(1970, 1066)

4162 = 1·94 + 68

668 = 2·26 + 16
726 = 1·16 + 10
816 = 1·10 + 6
910 = 1·6 + 4
106 = 1·4 + 2
114 = 2·2 + 0
=gcd = 2
1.3Extended Euclidean algorithm

Track two extra numbers, get the inverse for free.

Goal

Find integers x, y with a·x + b·y = gcd(a, b).

Why it gives the inverse

If gcd(a, n) = 1 then a·x + n·y = 1. Reduce mod n: a·x ≡ 1, so a⁻¹ = x mod n.

Table method
  • Row −1: r = a, x = 1, y = 0.  Row 0: r = b, x = 0, y = 1.
  • Each new row: q = ⌊rᵢ₋₂ / rᵢ₋₁⌋
  • rᵢ = rᵢ₋₂ − q·rᵢ₋₁, and the same formula for x and y.
  • Stop when r = 0. The row above holds gcd, x and y.
  • Check every row: a·x + b·y = r.

1.3Finite fields GF(p)

A clock with a prime number of hours is a field.

Definition

For a prime p, GF(p) is the set ℤₚ = {0, 1, …, p−1} with addition and multiplication mod p. A finite field always has pⁿ elements; GF = Galois field.

Why prime works

Every w from 1 to p−1 has gcd(w, p) = 1, so extended Euclid gives w⁻¹. That is axiom M7. For composite n, ℤₙ is only a commutative ring.

The smallest field · GF(2)
+ is XOR
× is AND

Inverses: additive −0 = 0, −1 = 1; multiplicative 1⁻¹ = 1.

1.4Polynomial arithmetic

A polynomial is just a list of coefficients.

Definition

A polynomial of degree n (n ≥ 0):  f(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀,  aₙ ≠ 0.
The aᵢ are coefficients from a coefficient set S. Monic: aₙ = 1. We never substitute a value for x; x is a placeholder.

Three kinds of polynomial arithmetic
1

Ordinary

Usual algebra rules, integer or real coefficients.

2

Coefficients mod p

Coefficients come from GF(p). With p = 2: bits.

3

Coefficients mod p, polynomials mod m(x)

m(x) irreducible of degree n. This builds the field GF(pⁿ).

1.4Division · irreducible · gcd

Polynomials have “primes” and a Euclid too.

Division algorithm

f(x) = q(x)·g(x) + r(x),  deg r < deg g.
Write r(x) = f(x) mod g(x). If r(x) = 0 then g(x) | f(x).

Irreducible (prime) polynomial

Cannot be written as a product of two lower-degree polynomials over the field.

✓x⁴ + x + 1 is irreducible over GF(2)
✗x³ + x² + x + 1 = (x + 1)(x² + 1)
Polynomial GCD (Euclid again)

gcd[a(x), b(x)] = gcd[b(x), a(x) mod b(x)]. Repeat until the remainder is 0.

Example over GF(2)
gcd(x⁶+x⁵+x⁴+x³+x²+x+1, x⁴+x²+x+1)
= x³ + x² + 1

Quick test over GF(2): an even number of terms means x + 1 is a factor.

1.4Kind 3 · modular polynomial arithmetic

256 isn’t prime. So we build a different field.

Computers want a field with 2ⁿ elements so that every n-bit pattern is an element. But ℤ₂ⁿ is not a field: in ℤ₂₅₆, 2 has no inverse.

How often each value appears in the 7×7 multiplication table of 1–7
value01234567
ℤ₈548412484
GF(2³)07777777

Uneven counts create patterns attackers exploit. GF(2³) is perfectly even.

Construction of GF(2ⁿ)
  • Elements: all polynomials of degree < n with coefficients in GF(2). There are 2ⁿ of them, one per n-bit pattern.
  • Addition: XOR of the bit patterns.
  • Multiplication: multiply, then take the remainder mod an irreducible polynomial m(x) of degree n.
  • Result: a field. Every non-zero element has an inverse.

1.4GF(2⁸) · AES

AES does its byte maths in GF(2⁸).

1.4Implementation trick

Multiply by x = shift left, then maybe XOR 1B.

1.4Key points to remember

Unit 1.4 in six lines.

1

A polynomial is a list of coefficients; x is only a placeholder.

2

Over GF(2): add = subtract = XOR; equal terms cancel in pairs.

3

f = q·g + r with deg r < deg g. Irreducible = cannot be factored.

4

GF(2ⁿ): polynomials of degree < n, reduced mod an irreducible m(x) of degree n.

5

A generator g lists every non-zero element as gᵏ; multiply by adding exponents.

6

AES: GF(2⁸), m(x) = x⁸ + x⁴ + x³ + x + 1; ×{02} = shift, then ⊕ 1B if needed.
