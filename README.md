## Using the slides

Open `index.html` in any modern browser. It is a single self-contained file (fonts load from Google Fonts when online).

- `←` `→` or `Space`: previous / next slide
- `M`: contents menu
- `N`: speaker notes
- `F`: full screen

Speaker notes are also written as comments above each slide in the HTML.
